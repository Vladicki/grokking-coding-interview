# Expanded Companion Guide

This directory is an original expanded companion to the Markdown files in this repo. It does not copy or reconstruct login-gated course pages. It distills the public pattern knowledge already present here into study notes, examples, and drills you can use without an account.

## What is included

- [Pattern field guide](pattern-field-guide.md): all 41 patterns with signals, invariants, examples, and traps.
- [Worked examples](worked-examples.md): original approach-level walkthroughs for common interview shapes.
- [Practice drills](practice-drills.md): short prompts for recognizing the right pattern before coding.

## How to use it

1. Read one pattern page in `patterns/`.
2. Read the matching card in the field guide.
3. Do the related drills without looking at the answer line.
4. For any missed drill, write the cue you failed to notice.
5. Only then code the problem from memory.

The goal is recognition first, implementation second. Most interview mistakes happen before code starts.
